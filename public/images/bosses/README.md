# Grafiki bossów

Wklej w folderze `public/images/bosses/` osiem prawdziwych plików JPEG:

- queen-ant.webp
- core.webp
- orfen.webp
- baium.webp
- zaken.webp
- frintezza.webp
- antharas.webp
- valakas.webp

Nazwy plików muszą być zapisane małymi literami. Nie wystarczy zmienić
rozszerzenia pliku PNG na JPG — wyeksportuj go do formatu JPEG.
Grafiki są kadrowane do istniejących miejsc bez zmiany układu strony.
Po dodaniu plików odśwież stronę. Przy publikacji wykonaj nowy build.

Boss jest rozpoznawany po pełnej nazwie wydarzenia (np. Queen Ant),
niezależnie od wielkości liter i nadmiarowych spacji. Brakujący lub
uszkodzony obraz pozostawia dotychczasowy placeholder.
